# 🔄 Convertir archivos HEIC a JPG

Los archivos HEIC (fotos de iPhone) no son soportados por los navegadores web.
Necesitas convertirlos a JPG para que se muestren correctamente.

## ✅ Soluciones Rápidas:

### Opción 1: Herramienta Online (Más fácil)
1. Ve a: https://convertio.co/es/heic-jpg/
2. Sube tus archivos HEIC
3. Descarga los JPG convertidos
4. Reemplaza los archivos en esta carpeta

### Opción 2: Windows (Gratis)
1. Descarga **CopyTrans HEIC** (gratis): https://www.copytrans.net/copytransheic/
2. Instala el programa
3. Haz clic derecho en los archivos HEIC → "Convert to JPEG with CopyTrans"
4. Los archivos se convertirán automáticamente

### Opción 3: Convertidor por Lotes Online
1. Ve a: https://heictojpg.com/
2. Arrastra todos tus archivos HEIC
3. Espera la conversión
4. Descarga el ZIP con todos los JPG

### Opción 4: Python Script (Avanzado)
```bash
pip install pillow-heif pillow
python convert_heic.py
```
