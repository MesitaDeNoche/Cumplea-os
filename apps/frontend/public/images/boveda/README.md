# Bóveda de Recuerdos - Galería de Imágenes

Esta carpeta contiene todas las imágenes que se mostrarán en la **Bóveda de Recuerdos**.

## Cómo agregar imágenes:

1. Coloca tus imágenes en esta carpeta: `public/images/boveda/`
2. Formatos soportados: JPG, JPEG, PNG, GIF, WEBP
3. Nombres sugeridos: `foto1.jpg`, `foto2.jpg`, etc. (o nombres descriptivos)

## La galería mostrará automáticamente:

- Todas las imágenes en esta carpeta
- Vista de cuadrícula responsive
- Lightbox para ver imágenes en tamaño completo
- Navegación entre imágenes
- Diseño melancólico y emotivo

## Ejemplo de estructura:

```
boveda/
  ├── foto1.jpg
  ├── foto2.jpg
  ├── momento-especial.png
  ├── recuerdo-favorito.jpg
  └── ...
```

**Nota:** La galería se actualizará automáticamente cuando agregues o quites imágenes de esta carpeta.
