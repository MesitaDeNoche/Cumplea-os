# Playlist Covers

Coloca aquí las imágenes de portada de las canciones de la playlist.

## Nombres de archivo:

- `inarow62.jpg` - Para la canción INAROW62. de Álvaro Díaz
- Agrega más imágenes con nombres descriptivos (sin espacios, en minúsculas)

## Formatos aceptados:
- JPG/JPEG
- PNG
- WEBP

## Tamaño recomendado:
- Mínimo: 300x300px
- Ideal: 600x600px o 1000x1000px
- Cuadrado (1:1 ratio)

## Ejemplo:
Si tienes una canción llamada "Con Altura", nombra la imagen:
`con-altura.jpg`
